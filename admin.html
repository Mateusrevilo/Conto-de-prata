Como criar o token?
  1. Acesse github.com/settings/personal-access-tokens/new
  2. Dê um nome (ex.: "Painel loja") e escolha a validade.
  3. Em Repository access, escolha Only select repositories e selecione o repositório do site.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Clique em Generate token, copie e cole aqui.
